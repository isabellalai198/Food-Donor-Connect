# 🍽️ DoaFood

## 📖 Sobre o Projeto

O **AlimentaBairro** é um aplicativo mobile desenvolvido para conectar moradores da comunidade a instituições de assistência social, facilitando a doação de alimentos lacrados e dentro do prazo de validade.

A plataforma busca reduzir o desperdício alimentar e ampliar o acesso a alimentos para famílias em situação de vulnerabilidade social, promovendo solidariedade e impacto positivo na comunidade.

---

## 🎯 Objetivos

* Combater o desperdício de alimentos;
* Facilitar o processo de doação;
* Conectar doadores e instituições de forma simples;
* Apoiar ações de assistência social;
* Incentivar a participação da comunidade.

---

## ✨ Funcionalidades

### 👤 Usuários

* Cadastro de doadores e instituições;
* Gerenciamento de perfil;
* Histórico de atividades.

### 📦 Doações

* Cadastro de alimentos disponíveis;
* Informações sobre quantidade e validade;
* Controle de status da doação.

### 🔍 Consulta

* Feed de doações disponíveis;
* Busca por categoria;
* Visualização detalhada dos itens.

### 🤝 Instituições

* Reserva de alimentos;
* Confirmação de coleta;
* Histórico de coletas realizadas.

## 🚀 Fluxo de Funcionamento

1. O usuário realiza seu cadastro;
2. Escolhe o perfil de doador ou instituição;
3. O doador cadastra alimentos disponíveis;
4. As instituições visualizam as doações;
5. Os itens são reservados para coleta;
6. A coleta é realizada;
7. A doação é marcada como concluída.
